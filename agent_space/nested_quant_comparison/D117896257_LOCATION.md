## Exact V0.3 hunks

- `torch/_inductor/decomposition.py`: exclude `aten._unsafe_index_put` from
  the Inductor decomposition table so its unchecked semantics reach lowering.
- `torch/_inductor/ir.py`: add optional `store_mask` to `Scatter`, preserve it
  through `constant_to_device`, and emit the scatter store through
  `ops.masked`; propagate the inherited field through the then-existing
  `PaddedScatter.constant_to_device`.
- `torch/_inductor/lowering.py`: change `index_put_as_masked_fill` to use a
  masked `Scatter` when the destination is named/materialized, the backend
  supports indexed masked scatter, the update is non-accumulating, and neither
  mask nor scalar value reads the destination. Preserve the existing
  `mutate_to(where(...))` fallback otherwise.
- `test/inductor/test_custom_lowering.py`: register a test-only masked scatter
  lowering and verify an out-of-bounds index under a false mask is not
  evaluated.
- `test/inductor/test_padded_scatter.py`: add the ATen XDL scatter construction
  and static/dynamic nested-reduction tests, asserting two generated kernels,
  one allocation, no device assertion, and a load-free padding kernel.
