What changed the number:
- Template key fix (core ms22; prototype TPL_DECLVAL): GDN prefill templates were keyed per layer because core's _reads keyed a
  mixed expression (a layer's own static-prefix size symbol times a per-call symbol) by its node. GDN full redos 729 -> 54,
  instances 135 -> 810; redispatch seconds 152-173 -> 69-83. Repro: learnfast/tests/test_declval_repro.py ((4, 0) -> (2, 2)).
- Cross-variant reuse (core ms21; prototype xvr.py): the redo dispatch cache keyed extents by absolute trace-time bytes; keyed by
  what the trace reads (length, empty, cow, overlaps) it serves mm_fp4 (816 hits) and trtllm attention (135) across variants and
  layers (core: 964 hits / 403 bodies). Worth ~10-40 s alone (redo bodies), GDN gets no hits (its misses are real class changes).
- Redispatch bookkeeping (core ms25 / ms26, from the wip25 counters): template guards renamed only through pinned static-prefix
  symbols are not renamed again (for_instance 17.0 -> 9.5 s, conjunction 6.6 -> 3.7 s); check_section caches per lowering /
  plan / step (13.0 -> 4.5 s).
- gc_untrack walk (core): 108-147 s per run on ms16, 56-87 s after the incremental walk (ms19/20), 67-72 s on ms22. ms23 (full
  walk by untracked count) 54-57 s; ms24 (sealed referents skipped) 17-19 s (incremental walks 821k -> 30k objects each).

Soundness: every arm's head was checked first with n27wf --check (prefill 97 rows, mixed 210 rows, bitwise and state bitwise):
ms24 (prefill), ms25 / ms26 / ms27 (mixed), ms16 + xvr (twice, the second with the extent watch and XVR_VALIDATE re-running the body on every hit: 876 identical), ms19 +
xvr + TPL_DECLVAL (validate + 747 tpl confirmations, 0 mismatches), ms20 + prototypes, ms22 core (core hits 204 / 672). No CUDA
errors in any run. Memory: live peaks equal eager's within 0.1-0.3 GiB in every run (reserved +7-13 GiB: QUESTIONS #7).

Prototype status (labelled in notes/NONDEFAULTS_learnfast.md): in the ms22 column, xvr and the template-key fix are core's; every
27B column (baselines included) still uses the 10-14/10-15 learnfast redo prototypes (lifted per-step state, closure / redo_context
stand-ins, fla_symlen overlay, tpl_layer layer-name / offset keyout, ARMV_PIN_UNPINNED); without them the GDN redispatch refuses
and the run retraces. GPU 0 runs ~5-10% slower than GPU 3 on the same code; compare within a GPU.
